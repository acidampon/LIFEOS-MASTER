# LIFEOS

LIFEOS is a personal life operating system for managing goals, habits, daily focus, growth, decisions, and achievements in one place.

## Foundation

The first production foundation is intentionally lightweight and mobile-first:

- Command Center dashboard
- Daily Focus
- Goals & Missions
- Habits
- Growth foundation
- Decision Room foundation
- Local-first persistence with browser storage
- Responsive mobile navigation
- Installable PWA foundation
- Offline fallback through a service worker

## Source of truth

GitHub is the canonical source for LIFEOS. Build changes should be committed here before deployment.
